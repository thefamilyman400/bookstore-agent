Deployment Checklist

1. Build & push Docker image to ECR
  • Create ECR repository: bookstore-agent
  • docker build -t bookstore-agent .
  • docker tag bookstore-agent <ACCOUNT_ID>.dkr.ecr.ap-south-1.amazonaws.com/bookstore-agent:latest
  • docker push ...
2. Create Secrets Manager secret
ARN referenced in task-definition.json as bookstore-agent-secrets
Store keys: JWT_SECRET · GROQ_MODEL
3. Create EFS file system + access point
SQLite DB persists across task restarts
Mount at /bookstore on EFS → /data/db in container
4. Replace placeholders in task-definition.json
<ACCOUNT_ID> <EFS_FILE_SYSTEM_ID> <EFS_ACCESS_POINT_ID>
5. IAM — Task Role permissions needed
  • secretsmanager:GetSecretValue on both secret ARNs
  • elasticfilesystem:ClientMount + ClientWrite on EFS resource
6. Register & run
  • aws ecs register-task-definition --cli-input-json file://task-definition.json
  • Create ECS Service (Fargate, awsvpc, behind ALB on port 8000)
